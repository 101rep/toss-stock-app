# 토스 증권 스타일 실시간 주식 뷰어

> 🌐 **실시간 웹사이트 바로가기**: **[https://101rep.github.io/toss-stock-app/](https://101rep.github.io/toss-stock-app/)**

토스 증권 특유의 **미니멀 감성 라인 차트(TradingView Lightweight Charts 공식 라이브러리)**와 **Yahoo Finance 무료 API(별도 승인 없는 전 세계 시세 & 과거 데이터)**, **미국/국내 주식 실시간 검색**, **거래량 폭증 & 상한가 TOP 100 탐색기**를 결합한 모바일 반응형 웹 애플리케이션입니다.

---

## 🌟 핵심 기능 및 100% 한국어 최적화

1. **토스 증권 감성 라인 차트 (`TradingView Lightweight Charts v4.2.1`)**
   - 상승 시 빨간색 그라데이션(`#f04452`), 하락 시 파란색 그라데이션(`#3182f6`)
   - 실시간 크로스헤어 연동: 마우스나 손가락으로 차트를 훑을 때 상단 가격, 등락률, 날짜가 해당 시점의 수치로 실시간 변경
   - 기간별 간편 탭: `1일`, `1주`, `1달`, `3달`, `1년`, `전체`
   - 차트 모드 전환: `토스 라인 차트` ⇄ `전문 캔들스틱 차트`

2. **Yahoo Finance API (무료 전 세계 실시간/과거 데이터)**
   - 별도 승인 및 과금 없이 미국 주식(`NVDA`, `TSLA`, `AAPL` 등) 및 국내 주식(`삼성전자`, `SK하이닉스` 등)의 분봉/일봉/주봉 히스토리 무제한 공급
   - 미국 주식 조회 시 **달러($)와 원화 환산 금액(약 N원)**을 동시 표기

3. **거래량 폭증 & 상한가/급등주 4대 조건별 TOP 100 랭킹**
   - `거래량 폭증 TOP 100`: 평균 거래량 대비 300%~1,000% 이상 세력 수급 유입 종목 포착
   - `상한가 / 급등주 TOP 100`: 상한가(+29.9% 이상) 및 최고 상승률 순위
   - `거래대금 상위 TOP 100`: 시장 중심 자금이 몰린 대장주 랭킹
   - `실시간 검색 상위 TOP 100`: 개인 투자자 관심 종목 순위
   - 국내 주식(KRX) ⇄ 미국 주식(US) 원클릭 전환

4. **한국투자증권(KIS) Open API 연동 모달**
   - 개인 한투 API 키 등록 시 전용 시세 채널 연동 지원
