# 토스 증권 스타일 실시간 주식 뷰어 (Yahoo Finance & Lightweight Charts)

토스 증권 특유의 **미니멀 감성 라인 차트(TradingView Lightweight Charts 공식 라이브러리)**와 **Yahoo Finance 무료 API(별도 승인 없는 전 세계 시세 & 과거 데이터)**, **미국/국내 주식 실시간 검색**, **거래량 폭증 & 상한가 TOP 100 탐색기**를 결합한 웹 애플리케이션입니다.

---

## 🌟 새로 적용된 2대 핵심 엔진

### 1. TradingView 경량 차트 (Lightweight Charts v4.2.1)
- **토스 증권 시그니처 Area (부드러운 면적 라인 차트)**:
  - 상승 시 은은한 빨간색 그라데이션(`#f04452`), 하락 시 파란색 그라데이션(`#3182f6`)
  - 실시간 크로스헤어 인터랙션: 마우스로 차트를 훑거나 터치할 때 상단의 큼직한 가격 및 등락률, 날짜가 해당 시점의 가격으로 부드럽게 실시간 동기화
- **기간별 원클릭 전환**: `1일 (1D)`, `1주 (1W)`, `1달 (1M)`, `3달 (3M)`, `1년 (1Y)`, `전체 (ALL)`
- **차트 모드 전환 토글**: `토스 라인 차트` ⇄ `전문 캔들스틱 차트`

### 2. Yahoo Finance API (무료 전 세계 실시간/과거 데이터)
- **별도 유료 계약 및 복잡한 승인 없이** 전 세계 모든 미국 주식(NYSE, NASDAQ) 및 국내 주식(코스피 `.KS`, 코스닥 `.KQ`)의 실시간 호가 및 분봉/일봉/주봉 히스토리 차트 데이터 자동 파싱
- **다중 연결 계층 지원**:
  1. 로컬 파이썬 브릿지 (`kis_api_bridge.py`의 `/api/yahoo/chart` 엔드포인트) 직통 통신
  2. 브라우저 단독 실행 시 공개 웹 프록시 자동 연결
  3. 네트워크 오프라인 시에도 끊김 없는 고정밀 실시간 틱 제너레이터 Fallback

---

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기 (가장 간편)
`실행하기_토스증권_클론앱.bat` 또는 `index.html` 파일을 더블 클릭하면 브라우저에서 즉시 열립니다.

### 방법 2: 로컬 통합 브릿지 서버 실행 (권장)
```bash
python kis_api_bridge.py
```
실행 시 자동으로 브라우저(`http://localhost:8092`)가 열리며 Yahoo Finance 및 한투 KIS API 프록시가 가동됩니다.
